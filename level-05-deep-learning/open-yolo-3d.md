# Open-YOLO 3D

> Boudjoghra 2024 · [Paper](https://arxiv.org/abs/2406.02548)

**One-line summary** — Fast open-vocabulary 3D instance segmentation that replaces the slow SAM + CLIP labeling pipeline with a real-time open-vocabulary 2D object detector, reaching roughly 16x speedups over prior methods.

## Problem

Open-vocabulary 3D instance segmentation showed strong promise, but at the cost of slow inference and heavy computation: prior methods rely on 3D CLIP features that require computationally expensive 2D foundation models — Segment Anything (SAM) for per-crop masks and CLIP for classification — aggregated from many views into 3D. Total inference can take minutes per scene, which rules out the real-world applications that need both fast and accurate predictions, such as online robotic mapping.

## Key ideas

- **Class-agnostic 3D proposals**: A 3D instance segmentation network produces class-agnostic instance masks from the point cloud; the open-vocabulary problem then reduces to *labeling* these masks with text-prompted categories.
- **SAM is redundant here**: The key observation — the projection of a class-agnostic 3D point-cloud instance into an image already holds the instance information, so running SAM on top only adds redundancy and inference time.
- **2D detection instead of masks + CLIP**: The authors empirically find that matching text prompts to 3D masks works better *and* faster with an open-vocabulary 2D object detector producing bounding boxes over the multi-view RGB images than with per-crop SAM + CLIP encoding.
- **Multi-view label transfer**: Each 3D mask is projected into the 2D views, matched against the text-prompted detections, and its final label is aggregated across views — resolving occlusion and viewpoint ambiguity by consensus.
- **Two evaluation regimes**: Validated both with ground-truth object proposals (pure labeling quality) and with class-agnostic 3D proposals generated by a 3D proposal network (full pipeline).

## Results & impact

Open-YOLO 3D achieves state-of-the-art performance on both ScanNet200 and Replica while obtaining up to ~16x speedup compared to the best existing method in the literature. On the ScanNet200 validation set it reaches 24.7% mAP while operating at 22 seconds per scene — turning per-scene open-vocabulary labeling from minutes into seconds. Code and models are public.

## Why it matters for SLAM

Open-vocabulary semantics is what lets a robot answer language queries about its map ("where is the fire extinguisher?"), but it only helps online robotics if it runs at interactive rates. Open-YOLO 3D demonstrated that lightweight 2D detectors can replace heavyweight foundation-model pipelines for labeling 3D instances, making open-vocabulary semantic mapping practical to attach to a live SLAM system rather than an offline post-process.

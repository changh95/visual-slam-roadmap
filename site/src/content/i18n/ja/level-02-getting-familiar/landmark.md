# Landmark

**ランドマーク（landmark）**とは、SLAMシステムが推定し地図に格納する、環境中の固定された再観測可能な特徴である。視覚SLAMにおける典型的なランドマークは3D点 $\mathbf{X}_j \in \mathbb{R}^3$ であり、複数の画像で検出されたキーポイントを3Dに三角測量し、再認識できるようにディスクリプタと関連付けたものである。ランドマークの集合が（疎な特徴点ベースのシステムにおいては）地図そのものである。

ランドマークはSLAM問題の2つの半分の間のループを閉じる。

- **ローカライゼーションはランドマークを使う**: 既知の3Dランドマークの2D観測が与えられると、カメラ姿勢が推定される（2D-3D対応 / PnP）。観測モデルは $\mathbf{z}_{ij} = \pi(T_i \mathbf{X}_j) + \mathbf{v}$ である——ランドマーク $j$ を姿勢 $i$ を通して投影すると、観測した位置に一致すべきである。
- **マッピングはランドマークを生成する**: 姿勢と2D-2D対応から、新しいランドマークが三角測量され地図に追加される。

この相互依存性——姿勢はランドマークを必要とし、ランドマークは姿勢を必要とする——こそが、SLAMが同時推定問題である理由である。ファクターグラフにおいては、姿勢とランドマークはいずれも観測ファクターによって結び付けられた変数ノードであり、バンドル調整はそれらを同時に精緻化する。

## パラメータ化

自明な表現——ユークリッド座標 $\mathbf{X} = (x, y, z)$——は唯一の選択肢ではなく、常に最良とも限らない。

- **ユークリッドXYZ**: 単純で最小限であり、点が十分な視差で良好に三角測量されればこれが理想的である。
- **逆深度（Inverse depth）**: 点を、あるアンカーカメラに対する視線方向と逆深度 $\rho = 1/d$ で表現する。遠方の点（$\rho \to 0$）や視差の小さい点は、ユークリッド空間では深度不確かさが極端に非対称になるが、逆深度ではほぼガウス的な不確かさとなる——このため、推定器は（回転を美しく制約する）遠方の特徴を、深度が確定するはるか前の最初の観測から使用できる。システムは通常、視差によって点が良条件になった時点でXYZに切り替える。

## データ関連付け（Data association）

観測を正しいランドマークにマッチさせることはフロントエンドの中心的責務であり、標準的な仕組みはいくつかのフィルタを積み重ねる。

1. **投影探索**: 現在の姿勢推定を用いてランドマークがどこに現れるべきかを予測し、その予測位置周辺の探索窓内にあるキーポイントのみを候補として考慮する。
2. **見え方チェック**: ランドマークに格納されたディスクリプタと候補キーポイントとのディスクリプタ距離が小さいこと（かつ比率/2位テストに合格すること）。
3. **整合性チェック**: 観測はランドマークのスケール範囲（ピラミッドレベル）と平均視線方向と整合していなければならない。
4. **統計的ゲーティング**: 推定後、再投影残差に対するカイ二乗検定によって、予測された不確かさと矛盾する関連付けを棄却する。

誤ったデータ関連付け——観測を誤ったランドマークにマッチさせること——はSLAMにおいて最も損害の大きい誤りの一つであり、これがロバストなマッチングと外れ値除去がそれほど注目される理由である。

## ランドマークのライフサイクル

実用的なランドマークは座標以上の情報を保持する。ORB-SLAM系システムにおける典型的な地図点は、3D位置、代表的なディスクリプタ（マッチング用）、視線方向の統計（どの方向から可視か）、スケール/深度範囲（どのピラミッドレベルで検出可能か）、そして信頼できない点を除去するための管理情報（観測回数、外れ値率）を格納する。ランドマーク管理は、実システムを健全に保つ大きな部分を占める。

- **生成**: 十分な視差、両視点での正の深度、小さな再投影誤差がある場合のみ三角測量する——そうでなければ新しい点はランドマークの衣を着たノイズにすぎない。
- **除去（Culling）**: 新しく生成された点は速やかに自らを証明しなければならない（本来観測されるべきフレームの一定割合以上で発見される、最小観測数を得る）。そうでなければ削除される。
- **統合（Fusion）**: 2つの地図点が実は同一の物理点であると判明した場合（例えばループクロージング後）、それらは統合され観測が結合される。

ランドマークは点である必要はない。線や平面（人工的なシーンにおけるより豊かな幾何）、物体レベルのランドマーク（姿勢を持つ認識済み物体）を用いるシステムもあり、検出の複雑さと、より記述的で意味論的に有意義な地図とをトレードオフしている。形態にかかわらず、要件は同じである。*静止*していること（そうでなければ特別に処理される）、*再観測可能*であること、そして信頼できるデータ関連付けのために十分に*識別可能*であることである。

## SLAMにおける意義

「ランドマーク」はオドメトリをSLAMへと変える概念である。ランドマークが持続するからこそ、長い移動の後に一つを再観測することで現在の姿勢を古い地図に対して制約でき、ドリフト補正、ループクロージング、リローカライゼーションが可能になる。特徴点ベースのシステムの論文を読むとき、そのランドマークの設計——何を格納するか、どのように生成・除去されるか、どのようにマッチングされるか——がその地図の設計そのものである。

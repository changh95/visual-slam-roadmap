CodeSLAM

Bloesch 2018 · 論文

一行要約 — CodeSLAM(CVPR 2018)は、各キーフレームの密な深度マップを画像条件付き変分自己符号化器からの小さな潜在コードとして表現し、密な幾何をカメラ姿勢と共同で最適化できるほどコンパクトにした。

問題

リアルタイム3D知覚における幾何の表現は、依然として重要な未解決課題である。密なマップは完全な表面形状を捉えるが、その高次元性ゆえに保存・処理のコストが高く、厳密な確率的推論には適さない。スパースな特徴ベースの表現は構造と動きの共同確率的推論を可能にするが、シーン情報の一部しか捉えられず、主に位置特定にしか有用でない。しかし自然なシーン幾何は高度に整然としている——隣接する深度値は強く相関している——ため、密な表現は実際には多数のパラメータを必要としないはずである。CodeSLAM は密でありながらコンパクトかつ最適化可能な表現を求める: 共同確率的最適化の内部に収まるほど少ないパラメータで完全な表面幾何を表す。

手法とアーキテクチャ

輝度条件付き深度自己符号化。 変分自己符号化器はキーフレームの深度マップを圧縮するが、画像だけでは予測できない情報のみをコードに保持するよう輝度画像を条件とする:

D=D(I,c)D = D(I, \boldsymbol{c})D=D(I,c)

ここで III は輝度画像、c\boldsymbol{c}c は潜在コード(参照ネットワークでは128次元)である。U-Net が III をマルチスケール特徴に分解し、対応する解像度で深度エンコーダ/デコーダに連結する; 変分ボトルネック(2つの512チャンネル全結合層、KL 正則化)はコードから深度への写像を滑らかに保つ。c=0\boldsymbol{c}=0c=0 とすることで、最も可能性の高い単一視点深度予測 D(I,0)D(I,0)D(I,0) が得られる。

不確実性を考慮した学習。 ネットワークはピクセルごとの平均 μ\muμ と不確実性 bbb を予測し、4段階のピラミッドレベルで観測深度 d~\tilde{d}d~ に対するラプラス分布の負対数尤度によって学習される:

ここで損失 Lp,LgL_p, L_gLp​,Lg​ は無効な対応をマスクし、2種類の誤差を重み付けし、Huber 重み付けを適用し、傾斜したまたはオクルージョンされたピクセルの重みを下げる。減衰付き Gauss–Newton ソルバーがすべてのコードと姿勢を更新する。トラッキングは現在のフレームを最後のキーフレームに、同じ機構(フォトメトリックコストのみ、coarse-to-fine)を用いて整合させる; PTAM 方式の全体システムはトラッキングとマッピングを交互に行い、古いキーフレームを線形事前分布へ周辺化する。

実験結果

  • コードサイズ: 再構成精度はコードサイズ128で飽和する; 色入力と非線形デコードは有意な改善をもたらさなかった。コードエントリのヤコビアンは、意味的に一貫した画像領域を制御するエントリを示す。
  • N フレーム SfM(SceneNet RGB-D): マスターキーフレームの近接度の RMS 誤差はフレームが追加されるにつれて単調に減少する——2.65×10−22.65\times10^{-2}2.65×10−2(1フレーム)から 2.14×10−22.14\times10^{-2}2.14×10−2(6フレーム)——密な幾何の真のマルチビュー精緻化を示している。
  • 汎化: 純粋に合成データで学習したにもかかわらず、実際の EuRoC と NYU V2 画像での2フレーム再構成が可能; EuRoC の結果は各約100ミリ秒の最適化ステップを50回使用した。
  • EuRoC MH_02 上の VO: スライディングウィンドウ(4キーフレーム)の視覚オドメトリとして実行すると、誤差は9 m走行後に約1 m——視覚慣性システムには及ばないが、合成データで学習した事前分布を用いた視覚のみの手法としては立派である; マップ更新レートは約5 Hz。

SLAMにおける意義

CodeSLAM は、DTAM 以来密な SLAM を阻んできた問いに答えた: 密な幾何を後付けで融合するのではなく、共同確率的最適化の内部に含める方法である。その核心的な教訓——最適化器と密なマップの間に学習された低次元パラメータ化を置く——は、学習ベース SLAM における最も影響力のあるアイデアの一つであり(CVPR 2018 ベストペーパー特別賞)、SceneCode、DeepFactors、NodeSLAM、CodeMapping を生み出し、ネットワークパラメータが再びコンパクトな最適化可能な幾何として機能する neural-implicit SLAM(iMAP、NICE-SLAM)を概念的に予見していた。

ロードマップ/レベル 05 · 深層学習+SLAM

Depth Anything 3

Lin 2025 · 論文

一行要約 — 単一のプレーンなTransformer（アーキテクチャ的特殊化のないバニラDINOv2）を、1つの最小限のターゲット——ビューごとの深度マップとピクセルごとのレイマップ——のみで学習し、既知・未知いずれのポーズであっても任意数のビューから一貫した幾何とカメラポーズを復元する。VGGTに対して平均でポーズ精度35.7%、幾何精度23.6%上回り、単眼深度でもDepth Anything V2を上回る。

問題

単眼深度、SfM、MVS、SLAMはいずれも画像から3D構造を復元するものであり、その違いはしばしば入力ビュー数だけである——にもかかわらず、この分野ではタスクごとに専用モデルを構築してきた。近年の統一モデル（DUSt3R、VGGT）には重要な限界がある：複雑な専用アーキテクチャ、ゼロからのマルチタスク同時最適化、そして大規模事前学習済みバックボーンを十分に活用できないことである。DA3は2つの最小限のモデリングに関する問いを立て、両方に肯定的に答える：(1) 予測ターゲットの最小集合は存在するのか、それとも多数の3Dタスクにわたる同時モデリングが必要なのか？(2) 単一のプレーンなTransformerで十分なのか？もう1つの障害はデータである：実世界の深度（COLMAP、アクティブセンサ）はノイジーで不完全であり、一方でクリーンな合成深度だけではカメラポーズ推定を実世界へ汎化できない。

公開の学術データセットのみを用いて学習される：H100 GPU 128台、20万ステップ、基準解像度504×504、サンプルあたり2〜18ビュー、12万ステップで正解ラベルから教師ラベルへ切り替える。同じレシピから単眼版の生徒モデル、メトリック深度モデル、フィードフォワード3DGSバリアント（画素整合したガウシアンパラメータを予測する追加のGS-DPTヘッド）が得られる。

実験結果

  • 新しい視覚幾何ベンチマーク（HiRoom、ETH3D、DTU、7Scenes、ScanNet++——89以上のシーン）：20設定中18設定で最先端；平均でVGGT（従来のSOTA）に対しカメラポーズ精度+35.7%、幾何精度+23.6%（アブストラクトより）。
  • ポーズ（Auc3）: DA3-Giant（11.0億パラメータ）はHiRoomで80.3——VGGT（11.9億パラメータ）の49.1、Pi3の67.0に対して；ScanNet++では85.0対62.6（2位に対し33%の相対的向上）；全ベースラインに対し少なくとも8%の相対的Auc3向上。
  • 再構成: 平均でVGGTに対し+25.1%、Pi3に対し+21.5%；VGGTより3倍小さいDA3-Large（バックボーン3.0億パラメータ）でも10設定中5設定で上回る。
  • 単眼深度（δ1\delta_1δ1​）: DA3はKITTIで95.3、NYUで97.4、SINTELで75.5、ETH3Dで98.6、DIODEで95.4——DA2（94.6 / 97.9 / 77.2 / 86.5 / 95.2）を上回る；単眼版の生徒モデルは97.1 / 98.0 / 82.3 / 98.8 / 96.5に達し、ETH3DではDA2を10%以上上回る。DA3-metricはETH3Dのメトリック深度でSOTA（δ1\delta_1δ1​ 0.917、UniDepthv2の0.863に対して）。
  • フィードフォワードNVS: ファインチューニングしたDA3はDL3DVでPSNR 21.33——VGGTバックボーンの20.96、専用モデルDepthSplatの19.24に対して——幾何品質がそのままレンダリング品質に転化する。
  • 効率: A100上、504×336で1画像あたり37.6 FPS（DA3-Giant）——VGGTの34.1に対して；80GBのA100 1台で900〜1000枚の画像を扱える（VGGTは400〜500枚）（DA3-Large: 78.4 FPS、1500〜1600枚）。同等サイズのVGGT型デュアルTransformerは単一バックボーンの性能の79.8%まで低下する——その差は完全な事前学習と、3分の2が未学習のブロックとの違いに起因するとされる。

SLAMにおける意義

DA3は、このロードマップが追う深層幾何の2つの流れを統合するものである。Depth Anything V2の後継として、密な単眼SLAMのためのより強力な差し替え可能な単眼深度事前分布であり、そのメトリックバリアントはスケール問題に直接対処する。DUSt3R/VGGT型の任意ビューモデルとして、SLAMシステムが必要とするまさにそのフロントエンド量——1回の順伝播でクリーンな点群へ融合可能な一貫したビューごとの深度とカメラポーズ——を出力し、しかもVGGTよりポーズ精度が高くビュー容量もおよそ2倍である。これはVGGT-SLAMのようなサブマップベースのシステムにとって重要である（論文はそうしたSLAM応用をこのモデルファミリーの利用者として引用している）。カメラトークン条件付けはSLAMにとって特に注目に値する：トラッカーのポーズ推定値をゼロから再推定するのではなく注入して幾何を改善できるからである。誠実な留保点として、DA3はフィードフォワード再構成でありSLAMそのものではない——ループクロージャ、再位置決め、大域バンドル調整は存在せず、出力は（メトリックバリアントを除き）メトリックではなくスケール正規化されており、動的シーンは明示的に今後の課題とされている。

関連ノート

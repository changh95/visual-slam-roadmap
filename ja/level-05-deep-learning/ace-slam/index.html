ACE-SLAM

Alzugaray 2025 · 論文

一行要約 — シーン座標回帰を中核的な地図表現として用いる初のニューラル暗黙的RGB-D SLAMシステムであり、ネットワークの重み自体が地図として機能することで厳密なリアルタイム動作を実現する。

問題

iMAP/NICE-SLAM系統のニューラル暗黙的SLAMシステムは、ネットワークが密な地図として機能できることを示したが、そのレンダリングベースの追跡とマッピングはカメラ光線に沿ったコストの高い体積積分を必要とするため、厳密なリアルタイム予算を満たせず、追加の機構(分離されたフロントエンド、バンドル調整、ループクロージングモジュール、動的物体のための意味マスキング)を必要とする。一方、シーン座標回帰は(DSAC → ACE → ACE Zeroを通じて)効率的で低メモリ、プライバシーを保護する暗黙的表現であり、極めて高速な再位置特定を実現するまでに成熟していた — しかし、それはあくまでオフラインのマッピングツールとしてであった。未解決の問いは、SCRをオンラインで、すなわちライブSLAMループの内部で、追跡・マッピング・再位置特定のための単一の表現として学習できるか、というものであった。

手法とアーキテクチャ

地図としてのSCR。 各RGB-Dフレーム {It,Dt}\{\mathcal{I}^t, \mathcal{D}^t\}{It,Dt} は、固定された特徴抽出器を通過し、MMM個の特徴 {(fit,xit,dit)}\{(\mathbf{f}_i^t, \mathbf{x}_i^t, d_i^t)\}{(fit​,xit​,dit​)}(記述子、2Dキーポイント、深度)を得る。キーポイントは局所3D座標 yit=πK−1(xit,dit)\mathbf{y}_i^t = \boldsymbol{\pi}^{-1}_{\mathbf{K}}(\mathbf{x}_i^t, d_i^t)yit​=πK−1​(xit​,dit​) に逆投影される。地図 M\mathcal{M}M は小さなシーン固有ネットワークであり、各特徴に対して直接大域座標 y~i=M(fi)∈R3\tilde{\mathbf{y}}_i = \mathcal{M}(\mathbf{f}_i) \in \mathbb{R}^3y~​i​=M(fi​)∈R3 を回帰する — 完全に並列であり、レイサンプリングは不要である。SLAMは、画素ごとの残差に対するポーズと地図の結合自己教師付き最適化である。

真値による教師も明示的な特徴マッチングも用いない — フレームは共有された暗黙地図を通じてのみ相互作用し、それによって創発的な暗黙的マッチングとソフトなループクロージングが生まれる。

TriMLPヘッド。 ACEの直接回帰MLP(HomMLP)の代わりに、コンパクトなMLPが3つの直交平面上の離散化グリッドに対する分類ロジットを予測する: CiXY,CiXZ,CiYZ=softmax(MLP(fi))C_i^{XY}, C_i^{XZ}, C_i^{YZ} = \mathrm{softmax}(\mathrm{MLP}(\mathbf{f}_i))CiXY​,CiXZ​,CiYZ​=softmax(MLP(fi​))。各平面はそのベースグリッド上の重み付き平均によって座標に投票し、例えば (x~iXZ,z~iXZ)=∑BXZ⊙CiXZ(\tilde{x}_i^{XZ}, \tilde{z}_i^{XZ}) = \sum B^{XZ} \odot C_i^{XZ}(x~iXZ​,z~iXZ​)=∑BXZ⊙CiXZ​ となり、最終的な座標は平面間の互換成分を平均する(x~i=12(x~iXY+x~iXZ)\tilde{x}_i = \tfrac{1}{2}(\tilde{x}_i^{XY} + \tilde{x}_i^{XZ})x~i​=21​(x~iXY​+x~iXZ​)、など)。この投票方式により、特徴は同じ3D点への複数の有効な経路を持つことになり、これはオンライン適応を高速化する帰納的バイアスである。

追跡=再位置特定。 各フレームのポーズは、予測座標と観測座標の剛体アラインメントによって推定される。Pt=arg⁡min⁡P∑i∥y~it−Pyit∥2\mathbf{P}^t = \arg\min_{\mathbf{P}} \sum_i \lVert \tilde{\mathbf{y}}_i^t - \mathbf{P}\mathbf{y}_i^t \rVert^2Pt=argminP​∑i​∥y~​it​−Pyit​∥2 であり、サンプリングされた三点組(最大 HHH 個の仮説)に対するRANSACの内部で閉形式(Kabsch–Umeyama)によって解かれる。勝者となった仮説のインライア比 λt\lambda^tλt は品質信号としても機能する。ポーズの事前情報は不要であり、追跡失敗後の再位置特定、フレームスキップ、動的物体に対する頑健性が自動的に得られる。

PTAM風のループ。 最適化サイクルは、ウィンドウ W\mathcal{W}W にわたってポーズ推定とマッピングを交互に行う。最新の WLW_LWL​ 個のキーフレーム、最新フレーム、および pt∝1∣P∣+α(1−λt)p^t \propto \tfrac{1}{|\mathcal{P}|} + \alpha(1 - \lambda^t)pt∝∣P∣1​+α(1−λt) の確率でサンプリングされる最大 WGW_GWG​ 個のキーフレーム — 整合性の低いフレームに偏らせる(ソフトなループクロージング)。特徴サンプリングも同様に偏らせ、マッピングは残差損失に対するサイクルあたり数回のSGDミニバッチであるため、サイクルあたりの計算量は一定である。特徴はデフォルトで1/8解像度の密なACEエンコーダ特徴である(疎なSuperPointもサポート)。抽出器は固定されたままである。

実験結果

すべての実験はRTX 4090 + i7-12700K上で行われ、3回の実行の平均値である。処理がフレーム間隔を超える場合、フレームはスキップされ、ライブ映像を忠実に模擬する。

  • 効率(Replica、デフォルト構成): ACE-SLAMは1.11MBの地図で29.71相当FPS = 99.0%のリアルタイム係数で動作し、これに対してESLAMは7.35FPS / 24.5% / 45.46MB、NICE-SLAMは0.33FPS / 1.1% / 95.86MB、Point-SLAMは0.27FPS / 0.9% / 27.23MB、iMAP*は0.15FPS / 0.5%であり、最大で2桁高速である。新しいフレームのエンドツーエンドの位置特定には11ms(ACE特徴)または13ms(SuperPoint)かかる。
  • 静的ATE RMSE: iMAPと競争力があり、NICE-SLAMに近づく。例えばReplicaのroom-0では0.027m(NICE-SLAMは0.017、iMAPは0.031)、TUMのfr2/xyzでは0.016m、fr1/deskでは0.083mであり、精度では最新のレンダリングベースパイプラインには及ばないが、厳密なリアルタイムで動作する唯一のシステムである。TriMLPはHomMLPを明確に上回る(例: ScanNet 0000: 0.164対0.364m; 0106: 0.319対0.765m)。
  • 動的TUM-RGBD、意味的事前情報なし: fr3/w/xyzでは0.072mであり、NICE-SLAMの0.302、意味情報を用いるNID-SLAMの0.071に対して優位である; fr3/s/staticでは0.007m — 常時作動するRANSACによる再位置特定が自然に動く領域を除去するため、専用の動的SLAMパイプラインに匹敵するか、それを上回る。

SLAMにおける意義

ACE-SLAMは、DSAC、ACE、ACE Zeroを通じてオフラインの再位置特定技術として成熟してきたシーン座標回帰が、メガバイト規模のプライバシー保護型地図を伴うライブSLAMループにおいて、追跡・マッピング・再位置特定・(ソフトな)ループクロージングのための唯一の表現として機能できることを示している。これは再位置特定器中心のSLAM設計の明快な実証であり、レンダリングベースのニューラル暗黙SLAMに対する厳密リアルタイムの対極であり、(現時点における)ACE系統の自然な到達点である。

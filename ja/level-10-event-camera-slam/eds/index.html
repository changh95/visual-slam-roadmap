EDS

Hidalgo-Carrió 2022 · 論文

一行要約 — EDS(Event-aided Direct Sparse Odometry)は、イベントとフレームを1つの光度フレームワークの中で融合する初の直接法単眼VOである。イベント生成モデルを介してキーフレームに対して追跡されるイベントが、高速運動がフレームのみの直接VOを破綻させるフレーム間の「盲目時間」でも追跡を維持する。

問題

DSOは、高勾度点のスパース集合上の光度バンドル調整によって、最も精度の高いフレームベースVOシステムの1つである。しかしその追跡は、連続するフレームが光度アライメントに十分重なることを前提としている。この前提は高速なカメラ運動、モーションブラー、低いフレームレートの下で破綻する。イベントはまさにこれらのギャップで欠けている信号を運ぶが、単純には組み込めない。直接法は絶対的な画像強度に対して動作するが、イベントは明るさの変化を符号化するからである。EDSはイベント生成モデルを介して両者の間の理論的な変換を提供する。

バックエンド。 7つのキーフレームからなるスライディングウィンドウ上での光度バンドル調整(2000〜8000点、8画素の残差パッチ、Huberノルム、Ceres)が姿勢と逆深度を精緻化し、それがフロントエンドにフィードバックされる。この設計は、DSOのPBAに差し替え可能なほどモジュール化されている。初期化には古典的な多視点幾何、学習型単眼深度、またはフレーム上のDSOの粗い初期化器が用いられる。

実験結果

  • ステレオDAVIS 240Cデータセット(bin、boxes、desk、monitor、モーションキャプチャによる真値): EDSはATEが1.1 / 2.1 / 1.5 / 1.0 cmであり、ステレオイベント手法ESVO(2.8 / 5.8 / 3.2 / 3.3 cm)、イベント+フレーム+IMUのUSLAM(7.7 / 9.5 / 9.8 / 6.5 cm)、EVO(13.2 / 14.2 / 5.2 / 7.8 cm、2つのシーケンスで早期に失敗)よりも良好であり、単眼かつIMUフリーであるにもかかわらずこれを実現している。回転誤差は0.99 / 1.83 / 1.87 / 0.60度。
  • フレームベースのベースラインと比較すると、EDSは平行移動において単眼ORB-SLAMより一貫して優れ、DSOと同程度である(高速なdeskシーケンスではより高精度、1.5 cm対10.0 cm)。ステレオORB-SLAMよりはわずかに劣る程度である。
  • 低フレームレートの検討: フレームレートが下がるにつれ、EDSの誤差はほぼ一定に留まるのに対し、DSOの誤差は急激に増大する(DSOのリカバリー追跡は10 FPS未満で失敗する)。EDSはループクロージングなしのORB-SLAMにも勝る。イベントが離れたフレーム間でも追跡を維持するためである。
  • 感度: 追跡は深度ノイズに対しては緩やかに劣化するが、コントラストしきい値のノイズが σC>0.15\sigma_C > 0.15σC​>0.15 を超えると急激に破綻する。
  • 本研究はまた、ハイブリッドシステムを評価するための新しいビームスプリッタ式イベント+フレームデータセット(EDSデータセット)を導入した。

SLAMにおける意義

EDSは「拡張としてのイベント」という哲学の直接法版に相当する。EKLTが特徴追跡を拡張し、Ultimate-SLAMが特徴ベースVIOバックエンドを拡張するのと同じ相補性が、光度ベースの直接オドメトリでも成り立つことをEDSは示した。成熟したフレームベースシステムが、全面的な再設計ではなく的を絞った変更でイベントを取り入れられることを実証し、既存の直接法SLAMパイプラインにイベントの頑健性を後付けするための青写真となった。

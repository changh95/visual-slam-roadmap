Camera calibration

カメラキャリブレーションは、既知のキャリブレーション対象を撮影した画像から、内部パラメータ行列 K\mathbf{K}K とレンズの歪みパラメータを求める処理である。正確なキャリブレーションがなければ、三角測量、ポーズ推定、エピポーラ探索など、以降のあらゆる幾何計算は系統的に誤ったものになる。

Zhangの方法

Zhangの方法(1999年)は標準的なキャリブレーション手順である。これは、複数の視点から撮影された平面チェッカーボードの画像を使用する。各画像は、既知の3Dボードコーナーと検出された2D画像コーナー間の対応関係を提供し、ホモグラフィ(画像からボードへの写像)と内部パラメータの両方に制約を与える。手順は以下の通り:

  1. 異なる姿勢で撮影された N≥3N \geq 3N≥3 枚の画像でチェッカーボードのコーナーを検出する。
  2. ボード平面と各画像との間のホモグラフィ HiH_iHi​ を計算する。
  3. 各 HiH_iHi​ から K\mathbf{K}K に関する制約を、r1⊥r2r_1 \perp r_2r1​⊥r2​ かつ ∥r1∥=∥r2∥\|r_1\| = \|r_2\|∥r1​∥=∥r2​∥ を満たす H=λK[r1,r2,t]H = \lambda\mathbf{K}[r_1, r_2, \mathbf{t}]H=λK[r1​,r2​,t] を用いて抽出する。
  4. 内部パラメータについて線形システムを解く。
  5. すべてのパラメータ(内部+外部+歪み)を非線形最小二乗法で精緻化する。

制約の由来。 H=[h1,h2,h3]H = [\mathbf{h}_1, \mathbf{h}_2, \mathbf{h}_3]H=[h1​,h2​,h3​] と書く。h1∝Kr1\mathbf{h}_1 \propto \mathbf{K}r_1h1​∝Kr1​ かつ h2∝Kr2\mathbf{h}_2 \propto \mathbf{K}r_2h2​∝Kr2​ であり、r1,r2r_1, r_2r1​,r2​ が正規直交であることから、各視点は対称行列 B=K−TK−1B = \mathbf{K}^{-T}\mathbf{K}^{-1}B=K−TK−1 の成分に関する2つの線形方程式を生む:

h1TB h2=0,h1TB h1=h2TB h2\mathbf{h}_1^T B\, \mathbf{h}_2 = 0, \qquad \mathbf{h}_1^T B\, \mathbf{h}_1 = \mathbf{h}_2^T B\, \mathbf{h}_2h1T​Bh2​=0,h1T​Bh1​=h2T​Bh2​

BBB は6個の未知数を持つ(スキューをゼロと仮定する場合は5個)ため、3視点で十分である。K\mathbf{K}K はその後、コレスキー分解のような手法によって BBB から復元される。これが、ボードを異なる姿勢で撮影する必要がある理由である — 平行な視点は冗長な制約しか与えない。

レンズ歪みモデル

実際のレンズは理想的なピンホールモデルから逸脱する。標準的な2つのモデル:

**半径方向歪み(radial distortion)**は直線を曲線に見せる:

xd=x′(1+k1r2+k2r4+k3r6),yd=y′(1+k1r2+k2r4+k3r6)x_d = x'(1 + k_1 r^2 + k_2 r^4 + k_3 r^6), \qquad y_d = y'(1 + k_1 r^2 + k_2 r^4 + k_3 r^6)xd​=x′(1+k1​r2+k2​r4+k3​r6),yd​=y′(1+k1​r2+k2​r4+k3​r6)

ここで r2=x′2+y′2r^2 = x'^2 + y'^2r2=x′2+y′2 は主点からの距離の二乗である。k1>0k_1 > 0k1​>0 は樽型歪み(barrel distortion)を、k1<0k_1 < 0k1​<0 は糸巻き型歪み(pincushion distortion)を与える。広角レンズは大きな ∣k1∣|k_1|∣k1​∣ を持つ。

**接線方向歪み(tangential distortion)**は、レンズが画像平面に完全に平行でないことによって生じる:

xd=x′+2p1x′y′+p2(r2+2x′2),yd=y′+p1(r2+2y′2)+2p2x′y′x_d = x' + 2p_1 x'y' + p_2(r^2 + 2x'^2), \qquad y_d = y' + p_1(r^2 + 2y'^2) + 2p_2 x'y'xd​=x′+2p1​x′y′+p2​(r2+2x′2),yd​=y′+p1​(r2+2y′2)+2p2​x′y′

実際には、k1,k2k_1, k_2k1​,k2​(場合によっては k3,p1,p2k_3, p_1, p_2k3​,p1​,p2​)は K\mathbf{K}K と同時に推定される。OpenCVは cv::calibrateCamera() でこれを直接実装している。

キャリブレーション品質の判定

標準的な品質指標は、キャリブレーションが返すRMS再投影誤差である。推定パラメータでボードのコーナーを再投影し、ピクセル残差を測定する。単一の数値だけでなく、以下も確認すること:

  • 残差が画像全体に均等に分布しているか — コーナー部分での偏りは、不適切な歪みモデル(例えば魚眼レンズを半径方向・接線方向モデルに強制的に当てはめた場合)を示している。
  • ボードが画像のすべての領域、特にコーナーやエッジに現れているか — この領域で歪みが最も強く、そうでなければ制約が不十分になる。
  • 傾きを含む視点が十分にあるか(正面からの撮影だけではなく) — これにより焦点距離と主点の相関が解消される。

よくある落とし穴

  • 撮影中のモーションブラーとローリングシャッターはコーナー検出を損なう。各撮影時にはボード(またはカメラ)を静止させること。
  • 平面でないボード: カードボードに貼った印刷紙は反ってしまい、歪みの推定値がその反りを吸収してしまう。剛性のある平らなターゲットを使用すること。
  • 画像の境界付近の姿勢が少なすぎること — 高次の半径方向項がその領域に過剰適合し、カバーされていない範囲で大きく外れた値を出す。
  • ある焦点/ズーム設定でキャリブレーションし、別の設定で運用すること: 内部パラメータは焦点によって変化する。レンズを固定し、ハードウェア設定が変わるたびに再キャリブレーションすること。

SLAMにおける意義

SLAMシステムは、歪みが補正され、キャリブレーション済みの観測が幾何ソルバーに供給されることを前提としている。画像境界における数ピクセルの未補正歪みが再投影誤差を支配し、マップを損なうことがある。キャリブレーションは、後で出会うより難しい問題のテンプレートでもある — カメラ-IMUやカメラ-LiDARの外部パラメータキャリブレーションは、同じ「既知のターゲット+非線形精緻化」というパターンに従う。実践的には、チェッカーボードで自分のカメラをキャリブレーションすることは、この分野における最良の最初の演習の一つである。
